# ABTalks – 60-Day Code Challenge

## 📌 Project Overview

ABTalks is a web-based **60-Day Coding Challenge Platform** created to help college students develop consistent coding and software development habits.

Students participate in a structured 60-day challenge where they build, practice, and document their development work every day. Each day's progress can be supported through **GitHub commits and LinkedIn posts**, allowing students to create a visible record of their learning journey.

The platform provides a centralized environment where developers can track their progress, maintain coding streaks, view achievements, analyze performance, and showcase their work to others.

---

## ❗ Problem Statement

Many college students learn programming and development skills but struggle to maintain **consistency and discipline** in their learning journey.

The major problems include:

* Students start coding challenges but stop after a few days.
* There is no structured system to maintain daily coding consistency.
* Students find it difficult to track their progress over several weeks.
* Coding practice and project work are often scattered across different platforms.
* Students may build projects but fail to document their progress publicly.
* Recruiters cannot easily see evidence of a student's consistent development activity.
* Students lack motivation when there is no visible comparison or recognition.
* GitHub commits and LinkedIn posts are not always organized into a single learning journey.
* Existing coding platforms mainly focus on solving problems rather than showcasing **long-term project-building consistency**.

### Core Problem

> **Students need a structured platform that transforms daily coding practice into measurable, trackable, and publicly visible proof of their development journey.**

---

## 💡 Proposed Solution

ABTalks solves this problem by providing a dedicated **60-Day Coding Challenge platform**.

Students can:

1. Join the 60-day challenge.
2. Select or follow a development track.
3. Complete coding or development work every day.
4. Submit their daily progress.
5. Maintain a coding streak.
6. Connect their work with GitHub and LinkedIn.
7. Track their performance through analytics.
8. Earn achievements and milestones.
9. Compare progress through a leaderboard.
10. Showcase their developer profile publicly.

Instead of simply saying **"I know programming"**, students can demonstrate:

**Learn → Build → Commit → Share → Track → Showcase**

This creates a stronger portfolio and provides visible evidence of consistency.
