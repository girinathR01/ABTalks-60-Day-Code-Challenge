# ABTalks

> Code tonight. Show up tomorrow.

ABTalks is a 60-day coding challenge platform designed to help students build consistency, share their daily progress, and turn their coding journey into a public proof of work.

Instead of simply learning and collecting certificates, ABTalks encourages students to actually build, document their progress, maintain streaks, and demonstrate what they can do.

## 🚀 Features

- 🎯 60-day coding challenges
- 🔥 Daily coding streak tracking
- 📈 Progress and challenge tracking
- 👤 Student profiles
- 🧩 Bento-style progress dashboard
- 🌐 Public proof-of-work
- 🏆 Community-driven motivation
- 📱 Responsive mobile-first interface
- 🌙 Modern light/dark UI
- ✨ Smooth animations and micro-interactions

## 🎯 Why ABTalks?

Students often learn programming without having a consistent way to demonstrate their progress.

ABTalks focuses on three simple ideas:

**Build. Show up. Prove it.**

The platform turns daily coding into a visible journey that students can share with peers, mentors, and potential recruiters.
